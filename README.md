## Yapılandırma

Bot token'ı, API anahtarları gibi gizli bilgileri **asla** depoya eklemeyin. Bunun yerine ortam değişkenleri veya `.gitignore` ile hariç tutulan bir `.env` dosyası kullanın:

```env
# Örnek .env
BOT_TOKEN=buraya_token_yazin
```
